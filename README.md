# Spam Detection

## 📌 Project Overview

Spam Detection is a Machine Learning project that automatically classifies text messages or emails into two categories: **Spam** and **Not Spam**.

The project uses Natural Language Processing techniques to convert text data into a format that can be understood by a Machine Learning model. A Naive Bayes classification algorithm is then trained on the processed text data to identify patterns commonly associated with spam messages.

The trained model can accept new messages and determine whether the given message is likely to be spam or legitimate.

## 🚀 Features

- Accepts text messages as input
- Processes and analyzes text data
- Converts text into numerical features
- Uses Natural Language Processing techniques
- Implements the Naive Bayes classification algorithm
- Classifies messages as Spam or Not Spam
- Saves the trained model for future predictions
- Provides a simple prediction interface

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Natural Language Processing
- Naive Bayes
- Joblib

## 🔄 Machine Learning Workflow

1. Load the spam detection dataset
2. Clean and prepare the text data
3. Convert text into numerical features
4. Split the dataset into training and testing data
5. Train the Naive Bayes classifier
6. Evaluate the trained model
7. Save the model using Joblib
8. Load the trained model
9. Enter a new message
10. Predict whether the message is Spam or Not Spam

## 🎯 Objective

The primary objective of this project is to build a simple and practical text classification system using Machine Learning and Natural Language Processing. The project demonstrates how Machine Learning can be applied to automatically filter unwanted or potentially harmful messages.

## 📚 Learning Outcomes

This project provided practical experience with text preprocessing, feature extraction, Natural Language Processing, classification algorithms, Naive Bayes, model training, model serialization, and real-time text prediction.
